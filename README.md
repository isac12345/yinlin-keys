# Yinlin Keys

Keyboard Android super ringan: Java murni, tanpa library tambahan, satu View custom (digambar langsung di Canvas).

## Build lewat GitHub
1. Upload semua isi folder ini ke repo GitHub (pastikan folder `.github` ikut).
2. Buka tab **Actions**, pilih **Build APK**, klik **Run workflow** (atau otomatis jalan tiap push).
3. Tunggu selesai, lalu unduh artifact **YinlinKeys-apk** (isinya `app-release.apk`).
4. Pasang APK, buka app **Yinlin Keys**, ikuti langkah 1 dan 2 di layar.

APK di-sign dengan debug key, jadi langsung bisa dipasang.
