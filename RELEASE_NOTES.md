Yinlin Keys

Same app as v1.0.0. No new features in this build.

- SHA256SUMS.txt is attached so you can check the download.
- README screenshots are sharper.
- The dictionary, clipboard bar, themes, and undo are unchanged since v1.0.0.

Privacy: no internet permission, nothing you type is stored, and the last 20 copied items stay in
memory only and disappear when the keyboard process ends.

How to install: download the APK below and open it, allow installation from this source if asked, then
open Yinlin Keys and follow steps 1 and 2 on screen. Android 5 or newer.
